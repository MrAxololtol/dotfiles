# Wallpapers

15 still wallpapers are bundled with the desktop, including car photographs,
illustrated cities, anime art, Linux wallpapers and abstract backgrounds.
The preview below uses the actual files; the linked originals keep their full
resolution.

![Contact sheet of the 15 bundled wallpapers](../screenshots/wallpapers.jpg)

## Pick a wallpaper

`./install.sh` copies the collection to `~/Pictures/Wallpapers`.

- **`super + alt + e`** opens the sxiv thumbnail picker. Move to an image,
  press **`m`** to mark it, then **`q`** to apply it. If several images are
  marked, the first is used.
- **`super + alt + w`** applies a random image from the same folder.
- **`super + alt + x`** opens the collection for browsing.

The picker and random wallpaper command run `colorChange` after applying the
image. Add your own `.jpg`, `.jpeg`, `.png` or `.webp` files to
`~/Pictures/Wallpapers` to include them in the collection. Set `WALL_DIR` when
running `wallpaper-selector` or `changer` to use a different folder.
